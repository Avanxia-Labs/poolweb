# Trabajo extra

Carpeta para materiales del cliente que no forman parte directa del codigo de la web.

Usos sugeridos:

- Ideas y propuestas.
- Documentos de estrategia.
- Materiales comerciales.
- Referencias visuales.
- Notas de reuniones.
- Tareas o planes que no pertenecen a `src`, `public` o la configuracion tecnica del sitio.

Mantener aqui solo material que tenga sentido guardar junto al proyecto. Si algo es privado,
temporal o pesado, conviene excluirlo con `.gitignore` antes de usarlo.
